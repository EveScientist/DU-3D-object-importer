Upload a .obj mesh and download a ready-to-import DU construct blueprint.

Read before using. This tool fits your whole mesh into a single core (up to XXXXXL, 8192 units) — that path is clean and reliable. Multi-core tiling is suitable for simple shapes that cross core boundaries (a building, warehouse, hull block). For complex, curved shapes spanning multiple cores the seams will be sub-optimal and need manual repair in-game, because DU meshes each core independently. When in doubt, pick a core size large enough to hold the whole model.
